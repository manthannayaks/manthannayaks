# Setup

1. Create a **public** repository named exactly `manthannayaks`.
2. Upload the contents of this folder to the repository root (not the ZIP file itself).
3. Open **Settings → Actions → General → Workflow permissions** and enable **Read and write permissions**.
4. Open **Actions → Update GitHub profile stats → Run workflow** once.
5. The workflow refreshes your contribution calendar daily.

## Notes
- Your photograph was converted into `assets/portrait.svg`; the original photo is not included.
- The contribution dashboard uses GitHub GraphQL and the built-in `GITHUB_TOKEN`. No personal access token needs to be created or pasted.
- The repository name must match the username exactly for GitHub to show this as your profile README.
- Replace the LinkedIn placeholder with your exact profile URL and add links to your project repositories when ready.
